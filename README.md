🎬 Moviely – Movie & TV Series Web App
Moviely is a modern and responsive web application for exploring and managing movies and TV shows. It is built using a powerful tech stack including React, TypeScript, Next.js, and Tailwind CSS, and integrates with the TMDB API to provide up-to-date movie and series data.

🔧 Tech Stack
Frontend: React, TypeScript, Next.js

Styling: Tailwind CSS

API: TMDB (The Movie Database) API

Database: MongoDB

Deployment: Vercel

Rendering: Server-Side Rendering (SSR)

✨ Features
🔍 Browse Movies and TV Shows – Fetches real-time data from the TMDB API

❤️ User Favorites – Logged-in users can like and save movies/series

💬 Comment System – Users can leave comments on movies/series

📁 Personal Dashboard – View liked items and activity history in a clean UI

🌐 Fully Responsive – Mobile-first and optimized for all screen sizes

⚡ Server-Side Rendering (SSR) – Improves SEO and page load performance

🔐 Authentication – User login and session management

☁️ Deployed on Vercel
